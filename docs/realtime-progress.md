# SSE 实时同步实施记录（2026-10-03）

## 实施范围

已实现浏览器 SSE 基础、Header 控制、分析查询订阅、空间重置通知和多浏览器凭证隔离。没有新增依赖，也没有将尚在浏览器 repository 中的 O/S 业务伪装为后端实时业务。当前 MCP 默认仍为四个读取工具；读取不会产生变更事件。启用并授权 MCP 重置工具后，它和网页重置使用同一事务事件机制。

| Header 选项 | 当前标签页行为 |
| --- | --- |
| 关闭 | 关闭 SSE，不进行事件驱动更新；显式查询和页面重新进入仍会获取数据 |
| 仅提醒（默认） | 接收事件，对已订阅且落后的查询显示“有新数据”，用户点击后更新 |
| 自动更新 | 仅更新事件涉及的已订阅查询；300ms 合并事件，后台标签页推迟到恢复可见时处理 |

选择保存在 sessionStorage，各标签页独立。每个标签页最多一个 SSE 连接，不跨标签页竞争主连接。页面卸载时取消对应查询订阅；当前分析页订阅 reports，保留已应用的筛选与分页。事件不执行任意页面动作，不调用整页 reload。

空间重置或账号关联变化具有更大影响：保留已挂载页面及输入，阻止旧 generation 的 HTTP 和浏览器 repository 写操作，提示用户确认后载入新空间。即使选了自动更新，也不直接销毁这些草稿。关闭 SSE 时，回到页面的会话检查仍会发现空间变化，这是旧版本写入保护。用户主动点击重置则沿用原有确认流程。

## 后端合同

- `GET /api/v1/events` 使用同源 HttpOnly Cookie；沿用来源检查，不把 MCP Token 放入 URL 或浏览器存储。
- `change` 事件包含 id、workspaceId、generation、revision、type、source、operationId（可选）和 resources；不携带业务内容。
- `ready` 表示流可用，15 秒发送一次 `heartbeat`。这两种事件不设置 id，避免越过尚未消费的变更。
- 初次连接使用 `after`；原生重连的 `Last-Event-ID` 优先。游标绑定空间，非法、跨空间、超前或超过保留窗口时发送 `sync.required`，客户端重新查询所需数据。
- SQLite `workspace_events` 与领域写入在同一事务提交。每空间保留最近 1,000 条；持久化游标支持服务重启后的补发。一次最多补发 128 条。当前单实例 demo 每条连接以 750ms 周期读取事件，无 Redis 或消息代理。
- 每次读取重新验证浏览器凭证；后台心跳不延长登录有效期。会话失效时发送 `session.invalid`，客户端检查会话并延迟重连；连接开始即被拒绝的终止错误也会触发此流程。
- 写入超时按每次事件刷新，不受普通请求 60 秒总写超时影响；客户端退出或服务退出时释放流。

## 去重与后续业务接入

去重按查询分别记录已应用 revision。同一 reports 资源的两个查询不会因其中一个完成而同时被标记为最新。HTTP 结果已应用的版本不会因稍后到达的 SSE 再次查询；若事件先到，已在途的查询会被共享，结果仍旧时最多再补查一次。失败保留更新提示，允许手动重试，避免无限自动重试。

当前页面自己的重置通过 operationId 识别：HTTP 成功响应负责切换空间，提前到达的自身事件不会再次初始化页面。不能仅按“来自当前浏览器”忽略全部事件，因为其他查询仍可能受影响。

后续迁移业务时须同时完成以下接入，不需要新增一条页面专用长连接：

1. Go 领域写事务内调用 `repository.AppendEvent`，列出受影响资源；幂等回放和失败回滚不新增事件。
2. 查询返回同一数据库快照的 revision；修改响应只有包含完整相关查询结果时，才能确认该查询已更新。
3. 活动页面通过 `RealtimeService.observe` 声明资源、已应用版本、refresh 和可选 dirty 检查。只更新查询数据，不覆盖正在编辑的表单。
4. 增加领域级联影响和多客户端验收。工作台、审批中心等当前浏览器业务仍需按全栈计划迁移后才能支持普通业务的跨客户端同步。

## 数据库与部署

迁移 `004_realtime.sql` 将浏览器凭证与空间分离，并回填原有 Cookie。网页登录只轮换当前浏览器凭证，其他浏览器继续访问共享空间。每个浏览器凭证独立到期，空间本身沿用原有生命周期。

本地升级前已使用 SQLite 在线备份并检查完整性，备份在忽略目录 `data/backups/20261003-before-sse.sqlite`。回退旧版本应同时恢复匹配的数据库备份，不能仅切换旧二进制；旧版本不认识新迁移。

开发代理禁用压缩，避免 gzip 缓存 SSE；已在实际浏览器复现并修复。Nginx 示例为 `/api/v1/events` 增加关闭 buffering、cache、gzip 和 65 秒读取超时。部署时将该 location 合入现有站点，保留既有 TLS、MCP 和 OAuth 配置；示例不能替代现网完整配置。当前轮次只更新本地运行环境，没有远程部署或执行远程 nginx 校验。
