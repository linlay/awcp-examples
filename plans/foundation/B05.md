## B05 AWCP 调试与调用记录面板

状态：`done`；里程碑：M1。

前置任务：B02, B04。

交付物：

- 目录/章节查看、输入编辑、样例填充、字段错误、结果与取消入口。
- 请求耗时和业务状态变化展示，面板可收起。

验收条件：

- [x] 通过真实浏览器入口调用；不另建 Registry。
- [x] revision 失效时重新读取目录，不盲目重试写操作。
- [x] 区分协议调用事件与业务审计。

实现与验收：`AwcpDebugPanel` 通过 `window.awcp` 读取目录、章节、调用和取消请求；通过同一 Provider 的调用订阅记录协议事件，并订阅演示 repository 展示业务状态变化，明确标注其不是审计记录。测试覆盖合法样例、revision 失效不重试和取消；本地真实浏览器已验证可展开并读取首页空目录。使用说明见 [调试面板](../../docs/debug-panel.md)。
