## S03 投行立项与尽调协作

状态：`done`；里程碑：M2。

前置任务：B06, B07, O09-03。

交付物：

- 项目经理、项目成员、质控与内核人员；发行人、项目、底稿、问题单和审议记录。
- 创建项目 → 立项 → 尽调分工 → 提交底稿 → 问题整改 → 质控 → 内核审议 → 归档。
- 拟定 Action：securities.ib-project.create / submit；securities.diligence.assign / attach；securities.finding.resolve；securities.quality.submit。
- 正常、拦截、退回/恢复三类固定数据及可回放任务；记录 businessVersion 与审计。

验收条件：

- [x] 完整底稿且问题整改完成时可以流转至审议状态。
- [x] 缺底稿或阻断问题未解决时返回清单并阻止流转。
- [x] 退回补正保留底稿版本和问题历史，能重新提交。
- [x] 业务规则使用带版本的演示配置，不以简化逻辑宣称完整监管合规。
