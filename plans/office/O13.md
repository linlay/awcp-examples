状态：`done`；里程碑：M3。实现与验收见 [O13 资产与行政](../../docs/o13-assets-admin.md)。

前置任务：B02, B05, B06, B07。

交付物：

- 实现 设备领用与归还 的页面交互与 service 用例。
- 提供 office.asset.assign / return 对应的合同、合法样例与 Hook。
- 提供固定种子、人工步骤、自然语言任务及自动回放断言。

验收条件：

- [x] 资产与持有人状态同步；已占用设备拒绝重复领用。
- [x] 人工操作与 AWCP 调用共享业务入口，调用后界面及实际记录一致。
- [x] 至少一个失败分支有断言；通过真实两层 manual 发现后调用，不依赖 DOM 兜底。
