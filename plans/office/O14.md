# O14 项目与任务协作

每项计为一个办公任务，共 3 项；参数变体不另计数量。页面、业务、合同、数据和测试一起交付。

## O14-01 创建项目并拆解任务

状态：`done`；里程碑：M3。实现与验收见 [O14 项目与任务协作](../../docs/o14-project-collaboration.md)。

前置任务：B02, B05, B06, B07。

交付物：

- 实现 创建项目并拆解任务 的页面交互与 service 用例。
- 提供 office.project.create / task.create 对应的合同、合法样例与 Hook。
- 提供固定种子、人工步骤、自然语言任务及自动回放断言。

验收条件：

- [x] 任务关联项目、负责人和期限，依赖 ID 均存在。
- [x] 人工操作与 AWCP 调用共享业务入口，调用后界面及实际记录一致。
- [x] 至少一个失败分支有断言；通过真实两层 manual 发现后调用，不依赖 DOM 兜底。
