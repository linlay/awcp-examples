# B07 审批状态机、业务版本与审计

基础设施任务。工作流服务供后续 O09 及其他业务场景调用。

## B07 审批状态机、业务版本与审计

状态：`done`；里程碑：M1。

前置任务：B03, B04。

交付物：

- 可配置状态迁移、角色检查、业务幂等键、版本冲突和审计条目。
- 附件任务及异步 jobId/status 基础。

验收条件：

- [x] service 写入原子核查角色、当前状态与业务版本。
- [x] 重复提交不重复创建单据；requestId 不充当持久幂等键。
- [x] 取消不伪报回滚，已受理与已完成可区分。

实现与验收：`WorkflowService` 按单据类型接收状态迁移配置；默认演示流程覆盖提交、退回、补正重提和审批。创建单据与迁移在 repository 同步事务内核查有效人员、角色、状态和 `businessVersion`，处理待办、审计和业务幂等记录。B06 草稿保存也写入审计。附件任务通过 `jobId` 查询 `accepted / completed / failed / cancelled`；已完成任务的取消请求返回实际完成状态，不修改附件归属。旧版存储在内存中补齐 B07 字段，首次写入时升级到 schemaVersion 2。详细使用方式见 [工作流说明](../../docs/workflow-foundation.md)。

验证：`tests/workflow-service.test.ts` 覆盖重复创建/提交、状态迁移、版本和权限失败、审计、附件受理及完成/失败/取消、旧存储迁移；全项目 `check:core`、`check:plans`、lint、typecheck、测试和 build 已运行通过。正式 O09 页面、Action 和流程仍属于 O09-01～03。
