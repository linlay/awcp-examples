# 导航与信息密度改造（2026-10-03）

## 实施结果

- `/` 默认展示 O01 工作台；完整的 31 场景目录迁到 `/navigation`，从总 Header「站内导航」进入，支持名称、技术能力、编号搜索。
- 侧栏业务入口由 3 个扩展为 7 个：S01、S02、S04、S03、S05、O07、O06。每项展示业务名称与技术重点；没有新增业务领域或宣称其后端迁移已完成。全部场景的技术描述集中在 catalog，供导航和搜索共用。
- 分析页删除宣传式标题及长说明，保留简短统计口径；缩小外边距、面板内边距、指标高度、表格间距；宽屏图表改为两列组合，窄屏回到单列。
- 工作台增加已办页签、关键词搜索、办理日期筛选、每页 20 条分页。原 AWCP 今日待办查询、办理、日报 Action 合同保持不变。
- 审批中心增加每页 20 条分页，全选只针对本页，翻页／切换筛选清空选择；保留最多批量 20 条规则。窄窗口固定操作列，支持横向滚动查看其他列。
- 在线演示会话启用关联样本：默认 EMP-002 初始工作台 18 条待办／60 条已办，审批中心 14 条待办／45 条已办。已操作的既有会话数量随办理变化。
- `workbenchSamples` 启用扩充数据；核心协议回放的小型 fixture 保留原规模。扩充数据拥有合法的三位数字业务 ID、来源单据、待办、审批决定和审计；ID 分配避开已有记录。`workbenchSampleVersion` 避免重复补充，刷新保留办理结果，重置恢复样本。
- 新增申请人属于原主管的部门，保留同部门审批限制。新增 UI 文案及技术说明补齐英文，样本业务内容仍为虚构中文数据。

## 边界

本轮没有修改依赖，没有实施 O/S 领域的 Go/SQLite 迁移。新业务样本仍由会话隔离的浏览器 repository 承接，分析页继续查询后端独立历史样本。浏览器验收连接的后端使用 48 条小型分析样本；没有据此宣称 24,000 条性能验收通过。后端与外部宿主全场景验收不属于本轮验证结果。
