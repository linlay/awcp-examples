## S01 客户资料审核与适当性匹配

状态：`done`；里程碑：M2。

前置任务：B06, B07, O09-03。

交付物：

- 客户经理、审核人员；客户档案、问卷、产品信息、匹配与补正记录。
- 查询客户 → 补资料 → 风险评估 → 产品匹配 → 提交复核 → 归档。
- 拟定 Action：securities.client.read / patch；securities.suitability.evaluate / match；securities.review.submit。
- 正常、拦截、退回/恢复三类固定数据及可回放任务；记录 businessVersion 与审计。

验收条件：

- [x] 资料完整时生成评估与复核记录。
- [x] 缺资料、问卷过期、不满足演示匹配规则时返回原因，不能直接完成复核。
- [x] 退回补正后以新业务版本提交，重复提交不重复生成记录。
- [x] 业务规则使用带版本的演示配置，不以简化逻辑宣称完整监管合规。
